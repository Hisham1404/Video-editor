# Shot description prompt v1

You are analysing one shot from an edited short-form video reel.

You will be shown {n_frames} frames sampled evenly across the shot.

Return JSON only, with exactly these keys:

```json
{
  "shot_size": "one of: extreme wide | wide | medium wide | medium | medium close up | close up | extreme close up",
  "framing": "one of: single | two shot | three shot | group | over the shoulder | insert | establishing | unknown",
  "description": "one sentence naming the subject and what it is doing",
  "camera_motion": "one of: static | pan left | pan right | tilt up | tilt down | push in | pull out | arc | handheld | unknown"
}
```

Rules:

- Judge shot size by how much of the primary subject fills the frame, not by
  how far away the camera appears to be.
- If the frames disagree (the shot changes size partway), describe the
  dominant framing and set camera_motion accordingly.
- Use "unknown" rather than guessing. A wrong label is worse than an admitted
  one, because stage 6 matches against these fields.
- Output the JSON object and nothing else.
